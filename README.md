# 🤖 HELP - Chatbot de Saúde com IA

Chatbot mobile desenvolvido como **projeto de extensão da Universidade Cruzeiro do Sul** com foco em fornecer orientações básicas de saúde e educação preventiva utilizando inteligência artificial.

## 🚀 Objetivo do projeto

Desenvolver um chatbot capaz de:
- Responder dúvidas básicas sobre saúde
- Fornecer orientações educativas
- Simular conversas contextualizadas com apoio de IA

## 🛠️ Tecnologias utilizadas

- Expo (React Native)
- API do Gemini (IA generativa)

## 🧠 Principais aprendizados

Durante o desenvolvimento, foi possível aplicar na prática:

- Consumo de API de IA generativa
- Engenharia de prompts
- Arquitetura para comunicação cliente-servidor
- Organização de código para projetos reais
- Estrutura de pastas e componentes em React Native

## ⚠️ Observação importante

O projeto utilizava a **API gratuita do Gemini**, que foi descontinuada.  
Com isso, a funcionalidade principal do chatbot ficou inviável sem migração para plano pago.

O projeto permanece como registro técnico do aprendizado em integração de IA em aplicações mobile.
